# TVM Calculator

A single-page HTML application for BS3210 Assignment 1.

## Overview

The application implements the seven required TVM calculations:

1. Future Value
2. Present Value
3. Simple Interest
4. Compound Interest
5. EMI Calculation
6. Loan Amortization Schedule
7. Scenario Analysis at 8%, 10%, 12%, and 15%

## Interface

The project intentionally uses **one HTML file** while keeping the interface uncluttered.

A left navigation panel switches between calculator views. Only the selected calculator is shown, so users do not have to scroll through all seven calculators on one page.

## Files

```text
TVM-Calculator/
└── index.html
```

All HTML, CSS, and JavaScript are contained in `index.html`.

## Features

- White and light lavender visual theme
- Responsive layout
- Input validation
- INR currency formatting
- EMI summary
- Automatically generated amortization table
- Required four-rate scenario comparison
- No external libraries or build tools
